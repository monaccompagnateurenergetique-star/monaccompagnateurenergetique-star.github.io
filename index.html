L'installer sur votre téléphone

  1. Android (Chrome) : ouvrez l'appli, touchez le menu ⋮ puis « Installer l'application » (ou « Ajouter à l'écran d'accueil »).
  2. iPhone (Safari) : ouvrez l'appli, touchez le bouton Partager puis « Sur l'écran d'accueil ».
  3. Une fois installée sur Android, Atelier PDF apparaît dans le menu « Partager » : envoyez-y un PDF reçu par e-mail pour l'ouvrir directement.
